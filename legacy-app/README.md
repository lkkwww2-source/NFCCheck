# legacy-app (별도 프로그램 - 버그 수정 + 참여명단 제거)

이 폴더는 이 저장소에서 처음부터 새로 만든 시스템(위 `apps-script/`, `android/`)과는
**별개로 이미 운영 중인 다른 프로그램**의 수정본입니다. 사용자가 올린 원본 Apps Script +
안드로이드 소스를 바탕으로, 기존 기능(QR 자가출석, Teacher/View/Grade 웹, 담임허락체크
승인 흐름, 안드로이드 NFC 앱, 누적현황/통계, QR 메뉴)은 그대로 유지한 채 아래만 고쳤습니다.

## 고친 버그

1. **출석했는데 기록이 전송되지 않아도 아무 표시가 없던 문제** — 안드로이드 앱의 전송
   함수(`sendSingleLogToGoogleAsync`)가 실패해도 `Log.e`만 남기고 화면에는 아무 표시가
   없었습니다. 이제 실패하면 상태 메시지 + Toast로 반드시 알립니다.
2. **나중에 터치로 지난 기록을 입력해도 반영되지 않던 문제** — 안드로이드 앱이 서버에
   날짜를 전혀 보내지 않아, 항상 서버의 "지금"으로만 저장됐습니다. 이제 앱이 날짜를 직접
   고르고(HOME 탭 날짜 선택), 그 날짜를 그대로 서버에 보내 저장/조회합니다. '리셋'도 이제
   서버까지 실제로 지웁니다.
3. **늦게 기록된 출결이 엉뚱한 타임으로 집계되어 통계에서 빠지던 문제** —
   `buildUnifiedResponseData`가 저장된 타임을 무시하고 지금 시각으로 다시 계산했습니다.
   이제 저장된 신청월/요일/타임/날짜를 그대로 믿습니다.

세 하드코딩된 시간대 판정(NFC 태깅, 수동 처리, 안내 화면)도 하나의 표로 모았습니다
(`TIME_WINDOWS`, `resolveAttendanceSlot`, `currentSlotDescription`).

## 참여명단(사전신청) 제거

`참여명단입력(N월)` 시트(요일별/날짜별 사전 신청)를 더 이상 쓰지 않습니다. `NFC학생현황`
시트에 등록된 학생이면 월 구분 없이 날짜·타임에 상관없이 바로 출결을 기록합니다
(QR 자가출석, 담임 웹, 안드로이드 앱 모두 동일).

신청 명단이 없어졌으므로 **결석을 더 이상 자동으로 추론하지 않습니다.** 결석으로 남는
경우는 다음 세 가지뿐입니다.

- 학생이 `index.html`에서 "사유 제출"로 미리 결석을 알린 경우
- 담임이 `Teacher.html`의 "➕ 결석 처리 추가" 버튼으로 직접 지정한 경우 (신규 추가,
  담임이 직접 처리하므로 즉시 승인(Y) 처리됨)
- 담임이 안드로이드 앱 HOME 탭에서 수동으로 "❌ 결석 처리"를 누른 경우

`출결결과`/`담임허락체크` 시트의 칼럼 구조는 그대로입니다. 참여구분은 항상 `'자율학습'`로
채워지므로, Teacher/View/Grade와 통계 함수들의 `type === '자율학습' || '향상반'` 필터는
그대로 동작합니다.

## 배포 방법 (Google Apps Script, clasp 등)

`apps-script/` 안의 `.gs`/`.html` 파일들을 기존 Apps Script 프로젝트에 **그대로 덮어쓰기**
하면 됩니다. 시트 이름/칼럼 구조는 바꾸지 않았으므로 데이터 마이그레이션은 필요 없습니다.
단, 더 이상 `참여명단입력(N월)` 시트를 읽지 않으니 지워도 되지만, 과거 기록 확인용으로
남겨둬도 무방합니다(읽지 않을 뿐 참조하지 않아 오류를 내지 않습니다).

## 적용 방법 (안드로이드 앱)

`android/MainActivity.kt` 하나로 기존 `MainActivity.kt`를 교체하면 됩니다. 패키지/의존성
(Volley 등)은 기존과 동일합니다.
